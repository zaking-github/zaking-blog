# 引言

在 2024 年构建一个技术博客，我们不仅追求内容的呈现，更追求极致的**加载速度**与**开发体验**。

## 为什么选择 Server Components?

RSC (React Server Components) 允许我们在服务端直接渲染 Markdown，向客户端发送零 JavaScript 的 HTML。

```tsx title="src/components/post.tsx"
async function Post({ slug }: { slug: string }) {
  const content = await loadPost(slug);
  return <article>{content}</article>;
}
```
